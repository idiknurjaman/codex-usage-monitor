# Plans

This directory contains active implementation plans for this fork.

## Active

- [`2s-multi-account-monitoring`](./2s-multi-account-monitoring/README.md) — monitor up to two Codex accounts in one Windows taskbar widget without account switching.

## Execution convention

Each plan owns its scope, hard stops, phases, test matrix, and evidence ledger. Execute phases in order unless the plan explicitly authorizes parallel work. A phase is not complete until its acceptance criteria are proven and recorded in the evidence ledger.

For the 2S plan, Sidik is final product authority, Luna is the implementation writer/executor, and Sol performs architecture review and final audit.
